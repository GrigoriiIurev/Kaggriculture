# Feature Extractor

`src/kaggriculture/data/feature_extractor.py` переводит большие игровые наблюдения в числа для
нейросети.

## Что попадает в признаки

- время игры: шаг, день и час;
- наши деньги, деньги противника и разница между ними;
- открытые участки земли и количество работников;
- наши семена, склад и предметы в руках работников;
- цены, запасы рынка и активные городские магазины;
- две карты фермы: наша и противника;
- растения, животные, сорняки, урожай, полив, кормление и позиции работников.

Приватный склад противника неизвестен агенту, поэтому его в признаках нет.

## Сборка

Сначала должен быть построен набор переходов из replay:

```bash
python3 build_dataset.py
```

Затем создаются числовые признаки:

```bash
python3 build_dataset.py
```

Получатся три файла:

- `data/processed/features.jsonl.gz` — числовые признаки, следующее состояние,
  исходное действие агента, флаг конца игры и результат;
- `data/processed/feature_schema.json` — значение каждого индекса;
- `data/processed/feature_manifest.json` — размер и статистика набора.

## Разреженный вектор

Полный вектор содержит несколько тысяч мест, но большинство из них равно нулю.
Поэтому строка хранит отдельно индексы и значения:

```json
{"feature_indices":[0,5,17],"feature_values":[0.25,1.0,0.4]}
```

В обучающем коде его можно восстановить так:

```python
import numpy as np

x = np.zeros(feature_count, dtype=np.float32)
x[row["feature_indices"]] = row["feature_values"]
```

`final_reward`, `margin` и `outcome` являются ответами о результате игры. Их
нельзя подавать нейросети как вход во время выбора хода, иначе она получит
информацию из будущего.

При разделении на обучение и проверку надо делить по `episode_id`, а не по
отдельным строкам: ходы из одной игры не должны оказаться в обеих частях.
