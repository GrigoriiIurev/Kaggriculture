# Action Encoder, Decoder и Worker Dataset

## Action Encoder

`src/kaggriculture/core/action_codec.py` разбирает команду на три числовые части:

```text
operation_id — что сделать;
argument_id  — с каким предметом или культурой;
quantity     — сколько единиц.
```

Например, `['PICKUP', 'WHEAT', 4]` становится тремя числовыми целями. Полные
словари находятся в `data/processed/action_schema.json`.

## Action Decoder

Decoder выполняет обратное преобразование. Он также защищает игру от неверного
ответа модели. Например, попытка посадить корову превращается в `['PASS']`, а
неправильный рыночный приказ удаляется.

## Worker Dataset

Создается обычной командой сборки:

```bash
python3 build_dataset.py
```

Файл `data/processed/worker_dataset.jsonl.gz` содержит:

- общие признаки текущего состояния;
- список находящихся в нем работников;
- позицию и личный инвентарь каждого работника;
- правильную команду в исходном и числовом виде;
- поле `split` со значением `train` или `holdout`.

Все ходы одной игры всегда имеют одинаковый `split`. Это не позволяет модели
увидеть часть проверочной игры во время обучения.

Результат всей игры (`outcome`, `margin`, `final_reward`) записан рядом для
анализа и весов обучения, но не включен во входные признаки.
